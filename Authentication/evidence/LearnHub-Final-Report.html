API Contract

Base URL: http://localhost:5000/api. Protected calls require Authorization: Bearer <token>. The actual HTTP tests used PowerShell Invoke-WebRequest/Invoke-RestMethod; Postman and Newman were not installed. The request bodies below reflect the controllers and routes.

Method and endpointAccessRequest body / notes
GET /healthPublicNo body.
POST /auth/registerPublic{ name, email, password: "<redacted>", role }. Public registration permits student/instructor; an admin role request is downgraded to student.
POST /auth/loginPublic{ email, password: "<redacted>" }. Returns a JWT; token omitted here.
GET /auth/meBearer tokenCurrent authenticated user.
GET /coursesPublicOptional search and category query parameters.
GET /courses/:idPublicSingle course by MongoDB ID.
POST /coursesInstructor/Admin{ title, description, category, price }.
PUT /courses/:idOwner/AdminAny of title, description, category, price.
DELETE /courses/:idOwner/AdminNo body; removes related enrollments and course.
POST /courses/:id/lessonsOwner/Admin{ title, url, description }; URL must be HTTP(S).
POST /enrollStudent{ courseId }.
GET /enroll/my-coursesStudentReturns the student's enrollments.
PATCH /enroll/:id/progressStudent/owner{ progress }, numeric range 0–100.
GET /admin/analyticsAdminNo body.
GET /admin/usersAdminNo body; excludes password hashes.
PATCH /admin/users/:id/roleAdmin{ role: "student" | "instructor" | "admin" }.
